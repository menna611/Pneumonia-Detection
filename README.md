🫁 Pneumonia Detection from Chest X-Ray Images 🩺

A deep learning model deployed using Streamlit that detects Pneumonia (Viral vs Normal) from X-Ray chest images.
---------------------------------------------------------------------------------------------------
🚀 Project Overview
-
This application:

.Loads a trained CNN deep learning model

.Accepts chest X-Ray images from users

.Classifies them as:

✔️ Normal

❌ Viral Pneumonia

Shows prediction confidence scores

Allows users to view example dataset images
----------------------------------------------------------------------------------------------------
🧠 Model Information
-
The model was trained using:

Convolutional Neural Networks (CNNs)

TensorFlow / Keras

Early stopping to prevent overfitting

Accuracy optimized above 90% (depending on dataset)

Saved model format: pneumonia_model.h5
